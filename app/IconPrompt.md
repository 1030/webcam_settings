# App icon

Created with the built-in image generation tool. `AppIcon.png` is the source
image; `AppIcon.icns` contains the standard macOS icon sizes, packaged using
`sips` and `iconutil`.

## Generation prompt

Use case: logo-brand

Asset type: macOS Dock application icon for Webcam Settings, a utility for adjusting USB webcam exposure, white balance and colour and saving camera presets.

Primary request: Create one polished, distinctive macOS app icon. A single front-facing sculpted silver webcam with a large dark glass lens showing subtle blue-teal reflections, a small stand, and three clear short adjustment sliders integrated beneath the lens. Make the webcam and sliders a unified simple symbol.

Style/medium: refined dimensional macOS icon, restrained material shading, crisp silhouette, excellent legibility at 32 pixels.

Composition/framing: square 1024 x 1024 canvas, centered deep blue rounded-square icon tile with generous transparent margin around it (roughly 10 percent). The webcam fills the tile with balanced padding. Subtle soft shadow. Fully transparent outside the rounded square.

Constraints: no text, no letters, no watermark, no extra objects, no surrounding UI, only one icon.
